# 能力バトル ―自由記述型・超能力バトル―

行動を**自然文で書いて**戦う、2D見下ろし型の超能力バトルゲームです（個人用・外部公開なし）。
プレイヤーとCPUは同じ戦場で同時に動き、互いの行動計画は見えません。

## 起動方法

```bash
cp .env.example .env      # GEMINI_API_KEY を記入
npm start                 # → http://127.0.0.1:8787/
```

- Node.js 18 以上が必要です（追加パッケージは不要）。
- `GEMINI_API_KEY` が未設定でも遊べます。その場合は簡易のローカル日本語解析とルールベースのCPUで動きます。
- APIキーはサーバー（`server.js`）だけが持ち、ブラウザには送られません。サーバーは既定で `127.0.0.1` のみで待ち受けます。
- Gemini につながらない・遅い時は `npm run check` を実行すると、実際のゲームと同じ大きさの問い合わせを試し、所要時間や失敗の原因（APIキー・モデル名・利用上限・タイムアウトなど）を表示します。ゲーム中も、サーバーのターミナルに1回ごとの所要時間が出ます。
- flash 系のモデルは、既定で思考なし（高速）で問い合わせます。解釈の精度を上げたい場合は `.env` の `GEMINI_THINKING_BUDGET` を 1024 などにします（その分、応答は遅くなります）。
- `?debug` を付けて開くと、霧なし・CPUの計画表示ありの観戦モードになります（調整用）。

## 遊び方

戦闘は次の繰り返しです。

1. **入力ターン**：時間は止まっています。行動を書いて Enter で決定します。相手も同じ時点の戦況から、裏で作戦を立てています。
2. **実行**：双方の計画を同時に実行します。両者の計画が終わったら（最長でも約13秒で）止まり、次の入力ターンへ移ります。

- 例：「左の家に駆け込み、窓から敵の位置を確認する」
- 実行中も相手は動くので、近づく時は「追尾」が有効です（例：「敵を追いかけて殴る」「3mの距離を保って敵を尾行する」）。追尾は相手を見失うと、最後に見た位置や物音の位置を探します。
- 「〜したら」と書くと条件付きの行動になります（例：「敵が近づいてきたら足元を滑らせる」）。
- 「」で囲んだ部分はセリフです。相手に聞こえれば、相手の次の作戦の材料になります。
- 1回の指示は最大5手順・見積もり10秒まで。超えた分は実行されません。空欄のまま決定すると「様子を見る」になります。
- 敵は見えている時だけ表示されます。物音は波紋で表示されます。
- フィールドをクリックすると、座標や物体名が入力欄に入ります。
- 実行中は Space で一時停止できます。再生速度も変えられます。

## 仕組み

```
自然文 ─▶ Gemini（またはローカル解析）─▶ 生の行動計画(JSON)
                                         │
                       compilePlan：行動・能力・対象・射程・予算を検証
                                         ▼
               ゲームエンジン：移動・命中・ダメージ・能力効果を確定
```

- AI は「意図を手順に変換する」「CPUの作戦を立てる」だけを担当します。存在しない能力や効果は検証で弾かれ、勝敗はエンジンの物理状態とルールで決まります。
- CPU の観測（`buildObservation`）には、CPU本人が見聞きした情報だけが入ります。見えていない敵の現在位置、未観察の能力、プレイヤーの指示文は含まれません。
- CPU の作戦は入力ターンの開始時点で立てるので、プレイヤーの入力内容は使われません。Gemini が失敗・タイムアウトした時はローカル思考で代わりの作戦を立てます。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `server.js` | 静的配信と Gemini 中継（プロンプト・応答スキーマ） |
| `public/js/engine/data.js` | キャラクター・能力・基本行動・ルール定数 |
| `public/js/engine/world.js` | 戦場生成、視線、経路探索 |
| `public/js/engine/sim.js` | 戦闘シミュレーション（物理・知覚・音・ダメージ・ログ） |
| `public/js/engine/plan.js` | 行動計画の検証（compilePlan）と実行 |
| `public/js/engine/abilities.js` | 能力の効果処理 |
| `public/js/engine/perception.js` | AI に渡す観測情報 |
| `public/js/engine/localParser.js` | Gemini なしで使う日本語解析 |
| `public/js/engine/localAI.js` / `controller.js` | ルールベースCPU、ターン進行（入力→同時実行→入力） |
| `public/js/main.js` / `render.js` | 画面・入力・描画 |

エンジンは DOM に依存しないので、Node.js でも動きます（`npm test`）。

## 能力の追加

1. `data.js` の `ABILITIES` に能力データ（効果・対象・射程・発動時間・クールダウン・コスト・弱点など）を追加
2. `abilities.js` の `IMPL` に同じ id で効果処理を実装
3. `data.js` の `CHARACTERS` で、キャラクターの `abilities` に追加
