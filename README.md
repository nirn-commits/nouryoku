# 能力バトル ―自由記述型・超能力バトル―

行動を**自然文で書いて**戦う、2D見下ろし型の超能力バトルゲームです（個人用・外部公開なし）。
プレイヤーとCPUは同じ戦場で同時に動き、互いの行動計画は見えません。

## 起動方法

```bash
cp .env.example .env      # GEMINI_API_KEY を記入
npm start                 # → http://127.0.0.1:8787/
```

- Node.js 18 以上が必要です（追加パッケージは不要）。
- `GEMINI_API_KEY` が未設定でも遊べます。その場合は簡易のローカル日本語解析とルールベースのCPUで動きます。
- APIキーはサーバー（`server.js`）だけが持ち、ブラウザには送られません。サーバーは既定で `127.0.0.1` のみで待ち受けます。
- Gemini につながらない・遅い時は `npm run check` を実行すると、実際のゲームと同じ大きさの問い合わせを試し、所要時間や失敗の原因（APIキー・モデル名・利用上限・タイムアウトなど）を表示します。ゲーム中も、サーバーのターミナルに1回ごとの所要時間が出ます。
- 既定のモデルは、料金の最も安い `gemini-3.1-flash-lite` です。使えない場合（存在しない・無料枠がない・上限に達した）は、`GEMINI_FALLBACK_MODELS` のモデル（既定：`gemini-3.5-flash-lite`、`gemini-3-flash-preview`）を順に試します。解釈の精度を上げたい場合は `.env` で `GEMINI_MODEL=gemini-3.8-flash` などに変えます。
- flash 系は既定で思考を最小限（`minimal`）にして速く返させます。解釈の精度を上げたい場合は `.env` の `GEMINI_THINKING_LEVEL` を `low` や `medium` にします（その分、応答は遅くなります）。
- `?debug` を付けて開くと、霧なし・CPUの計画表示ありの観戦モードになります（調整用）。

## 遊び方

2対2（あなた＋味方CPU 対 敵CPU2人）と1対1をタイトル画面で選べます。戦闘は次の繰り返しです。

1. **入力ターン**：時間は止まっています。行動を書いて Enter で決定します。相手も同じ時点の戦況から、裏で作戦を立てています。
2. **実行**：双方の計画を同時に実行します。両者の計画が終わったら（最長でも約13秒で）止まり、次の入力ターンへ移ります。

- 例：「左の家に駆け込み、窓から敵の位置を確認する」
- 実行中も相手は動くので、近づく時は「追尾」が有効です（例：「敵を追いかけて殴る」「3mの距離を保って敵を尾行する」）。追尾は相手を見失うと、最後に見た位置や物音の位置を探します。
- 「〜したら」と書くと条件付きの行動になります（例：「敵が近づいてきたら足元を滑らせる」）。
- 「」で囲んだ部分はセリフです。相手に聞こえれば、相手の次の作戦の材料になります。
- 1回の指示は最大5手順・見積もり10秒まで。超えた分は実行されません。空欄のまま決定すると「様子を見る」になります。
- 敵は見えている時だけ表示されます。物音は波紋で表示されます。
- フィールドをクリックすると、座標や物体名が入力欄に入ります。
- 実行中は Space で一時停止できます。再生速度も変えられます。

### 2対2

- 相手チームを全員倒せば勝ち。自分が倒れても味方が残っていれば、味方の視点で観戦して決着まで進みます。
- 味方とは連絡を取り合っている扱いで、味方の位置・様子は常に分かり、味方が見た敵の位置は「報告」として共有されます。
- 「鷺沼を殴る」「セブンス・サンを追いかける」のように敵の名前（姓・名・スタンド名）を書くとその敵を狙います。書かなければ見えている一番近い敵。「味方の所へ走る」で合流できます。
- 投げた物・跳弾は味方には当たりません（自分の跳弾は自分に当たります）。

### スタンドを出す・先行させる

- 「スタンドを出す」「スタンドを右へ先行させる」「スタンドで角の先を覗く」「スタンドを戻す」のように書けます。
- 先行させたスタンドは本体から射程（十河約2m・錠二約1.5m・鷺沼約1.2m）まで離れられ、壁は抜けられません。スタンドの位置からも周りが見えるので、角の先や窓の外を覗けます。
- 出している間は近接攻撃でスタンドが敵へ飛び出すため、拳の届く距離が伸びます（本体から離れた所で当たった拳は威力7割）。鷺沼の弾はスタンドの位置から撃てます。
- 敵の飛び道具がスタンドに当たると受け止めますが、本体にも3割の反動が返ります。
- 出している間はスタンドエネルギーが回復せず、毎秒2ずつ減ります（尽きると戻ります）。七海のエコー・ビーチは群体なので使えません。

### 演出

- 打撃が当たると、威力に応じたヒットストップ（一瞬の停止）・画面揺れ・集中線・擬音（ドゴォ、バキィ、ドギュン…）・大きなダメージ表示が出ます。
- 大ダメージは画面がフラッシュし、再起不能の瞬間はスローモーションになります。構え中のキャラには「ゴゴゴ」が出ます。
- 効果音はブラウザ内で合成しています（戦闘画面の「効果音」ボタンで ON/OFF）。
- エフェクト素材のスプライトシートを `public/fx/effects.png` に置くか、タイトル画面で選ぶと、その画像で描きます（`public/fx/README.md` 参照）。

## マップ

タイトル画面で選べます。

| マップ | 内容 |
| --- | --- |
| 住宅街（60m×40m） | 大通りと南北の道路で4区画に分かれた街。北西に住宅2軒、北東に工事現場（仮囲い・掘削穴・鉄骨・建設中の柱・現場事務所・ドラム缶）、南西にコンビニ（ガラス張りの店先・自動ドア・裏口・商品棚・レジ・自販機・駐車場）、南東に住宅と公園（植え込み・木・ベンチ・公衆トイレ） |
| 空き地（36m×24m） | 2軒の家と木箱の小さなマップ。すぐに接敵する |

- **植え込み**：通れるが遅く、葉擦れの音がする。中にいると、2.5m以内に近づかれない限り見つからない（中から外は見える）。
- **車**：遮蔽物になる。殴る・物をぶつけるなどすると防犯アラームが鳴り、半径40mに聞こえる（陽動に使える）。
- **重い物**：商品棚・自販機・ドラム缶なども押したり弾いたりできる。
- 広いマップでは「拡大表示」（Z キー）で自分の周りを大きく映せる。
- マップを追加するには `public/js/engine/maps.js` に配置を書き、`MAPS` に登録する。

## 仕組み

```
自然文 ─▶ Gemini（またはローカル解析）─▶ 生の行動計画(JSON)
                                         │
                       compilePlan：行動・能力・対象・射程・予算を検証
                                         ▼
               ゲームエンジン：移動・命中・ダメージ・能力効果を確定
```

- AI は「意図を手順に変換する」「CPUの作戦を立てる」だけを担当します。存在しない能力や効果は検証で弾かれ、勝敗はエンジンの物理状態とルールで決まります。
- CPU の観測（`buildObservation`）には、CPU本人が見聞きした情報だけが入ります。見えていない敵の現在位置、未観察の能力、プレイヤーの指示文は含まれません。
- CPU の作戦は入力ターンの開始時点で立てるので、プレイヤーの入力内容は使われません。Gemini が失敗・タイムアウトした時はローカル思考で代わりの作戦を立てます。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `server.js` | 静的配信と Gemini 中継（プロンプト・応答スキーマ） |
| `public/js/engine/data.js` | キャラクター・能力・基本行動・ルール定数 |
| `public/js/engine/maps.js` | マップの配置（住宅街・空き地） |
| `public/js/engine/world.js` | 戦場の部品（物体の種類・建物・塀）、視線、経路探索 |
| `public/js/engine/sim.js` | 戦闘シミュレーション（物理・知覚・音・ダメージ・ログ） |
| `public/js/engine/plan.js` | 行動計画の検証（compilePlan）と実行 |
| `public/js/engine/abilities.js` | 能力の効果処理 |
| `public/js/engine/perception.js` | AI に渡す観測情報 |
| `public/js/engine/localParser.js` | Gemini なしで使う日本語解析 |
| `public/js/engine/localAI.js` / `controller.js` | ルールベースCPU、ターン進行（入力→同時実行→入力） |
| `public/js/main.js` / `render.js` | 画面・入力・描画 |

エンジンは DOM に依存しないので、Node.js でも動きます（`npm test`）。

### 武器（拾える物）

初期装備はありません。マップのあちこちに置かれた物（花瓶・瓶・包丁・フライパン・鉄パイプ・ブロック・レンチ・角材・傘・消火器・石・木の枝）を拾って使います。「花瓶を拾って投げる」「鉄パイプを拾って殴る」のように書きます。持てるのは1つで、持っている物で殴ると威力・間合いが変わり、投げると手放します。花瓶や瓶は当たると割れます。

### キャラクター画像

- **ブラウザから**：タイトル画面の各キャラクターの「本体の画像…」「スタンドの画像…」ボタンで画像を選ぶと、その場で表示されます（ブラウザに保存され、次回以降も表示。「消す」で削除）。
- **ファイルで**：`public/img/` に `<id>.png`（本体）と `<id>_stand.png`（スタンド）を置きます（jpg・webp も可）。詳しくは `public/img/README.md`。
- 表示される場所：キャラクター選択カード、戦闘画面の左右の情報欄（本体）、能力発動時のカットイン（スタンド画像。無ければ本体）。

## 高さと建物

- 1階分は3m。2階建ての家（左の家・佐藤家・鈴木家・高橋家）は階段で上り下りできる（約1秒）。
- 物体には高さがあり、視線と飛び道具は高さも含めて判定する。ブロック塀（1.8m）や車（1.5m）は地上の視線を遮るが、2階の窓からは越えて見下ろせる。床・天井は階をまたぐ視線を遮る。
- 扉は閉まっていると通れず見通せない（歩いてぶつかると自動で開ける）。扉と窓は開け閉めでき、開いた窓は通り抜けられる。コンビニのガラス窓は開かず、割るしかない。
- 2階の窓から飛び降りられる（窓が閉まっていれば突き破る）。
- 表示は斜め見下ろし。建物は屋根で覆われ、中に入ると屋根が外れて今いる階が見える。

## 能力の追加

1. `data.js` の `ABILITIES` に能力データ（効果・対象・射程・発動時間・クールダウン・コスト・弱点など）を追加
2. `abilities.js` の `IMPL` に同じ id で効果処理を実装
3. `data.js` の `CHARACTERS` で、キャラクターの `abilities` に追加
