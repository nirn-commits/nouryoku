# 能力バトル ―STAND ARENA―

オリジナルのスタンド使いたちが、ランダム生成されたマップ上でターン制バトルを行う二次創作ゲームです（個人用・外部公開なし）。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド・サーバー不要）。

- 最大4名（2〜4名）で対戦。各枠は「プレイヤー」または「CPU」を選べます（1台のPCを交代で操作するホットシート方式）。
- バトル形式は「個人戦（バトルロイヤル）」と「チーム戦（2 vs 2）」。
- 毎ターン「移動」と「行動（攻撃／能力／ラッシュ）」を1回ずつ、好きな順番で実行できます。
- マップは毎回ランダム生成。壁は移動と視線を遮り、瓦礫は移動コスト2です。
- 攻撃する・受けるとラッシュゲージが溜まり、100で4連撃の「ラッシュ」が使えます。

## パラメータ

| パラメータ | 効果 |
| --- | --- |
| 破壊力 | 通常攻撃のダメージ |
| スピード | 移動力・行動順 |
| 射程距離 | 通常攻撃の届く距離（E=1 〜 A=6） |
| 持続力 | 最大HP |
| 精密動作性 | 命中率・会心率 |
| 成長性 | ラッシュゲージの溜まりやすさ |

## ファイル構成

- `js/data.js` … キャラクター・スタンドのデータ（キャラ追加はここ）
- `js/abilities.js` … スタンド能力の処理と CPU 用評価
- `js/map.js` … ランダムマップ生成・視線判定
- `js/game.js` … ターン進行・移動・ダメージ処理
- `js/ai.js` … CPU の思考ルーチン
- `js/ui.js` / `style.css` … 画面表示と操作

### キャラクターの追加方法

1. `js/data.js` の `CHARACTERS` に新しいキャラを追加し、`ability.id` を決めます。
2. `js/abilities.js` の `ABILITIES` に同じ id で `targets`（対象マス）、`execute`（効果）、`ai`（CPU の評価）を実装します。
