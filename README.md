# 能力バトル ―自由記述型・超能力バトル―

行動を**自然文で書いて**戦う、2D見下ろし型の超能力バトルゲームです（個人用・外部公開なし）。
プレイヤーとCPUは同じ戦場で同時に動き、互いの行動計画は見えません。

## 起動方法

```bash
cp .env.example .env      # GEMINI_API_KEY を記入
npm start                 # → http://127.0.0.1:8787/
```

- Node.js 18 以上が必要です（追加パッケージは不要）。
- `GEMINI_API_KEY` が未設定でも遊べます。その場合はプレイヤーの指示を簡易のローカル日本語解析で読み取ります。CPU の作戦はキーの有無にかかわらず、常にゲーム内蔵の思考（先読み）が決めます。
- APIキーはサーバー（`server.js`）だけが持ち、ブラウザには送られません。サーバーは既定で `127.0.0.1` のみで待ち受けます。
- Gemini につながらない・遅い時は `npm run check` を実行すると、実際のゲームと同じ大きさの問い合わせを試し、所要時間や失敗の原因（APIキー・モデル名・利用上限・タイムアウトなど）を表示します。ゲーム中も、サーバーのターミナルに1回ごとの所要時間が出ます。
- 既定のモデルは、料金の最も安い `gemini-3.1-flash-lite` です。使えない場合（存在しない・無料枠がない・上限に達した）は、`GEMINI_FALLBACK_MODELS` のモデル（既定：`gemini-3.5-flash-lite`、`gemini-3-flash-preview`）を順に試します。解釈の精度を上げたい場合は `.env` で `GEMINI_MODEL=gemini-3.8-flash` などに変えます。
- flash 系は既定で思考を最小限（`minimal`）にして速く返させます。解釈の精度を上げたい場合は `.env` の `GEMINI_THINKING_LEVEL` を `low` や `medium` にします（その分、応答は遅くなります）。
- `?debug` を付けて開くと、霧なし・CPUの計画表示ありの観戦モードになります（調整用）。

## 遊び方

1対1・2対2（あなた＋味方CPU 対 敵CPU2人）・5対5（あなた＋味方CPU4人 対 敵CPU5人）・バトルロワイヤル（3〜8人、全員が敵）をタイトル画面で選べます。出場キャラは枠ごとに選ぶかランダムで、同じキャラ同士も戦えます（名前に①②…が付きます。「ランダムでも同じキャラを重ねる」にすると、ランダムの枠も重複して選ばれます）。戦闘は次の繰り返しです。

1. **入力ターン**：時間は止まっています。画面下のコマンドで行動を組み立てて「決定」します。相手も同じ時点の戦況から、裏で作戦を立てています。
2. **実行**：双方の計画を同時に実行します。両者の計画が終わったら（最長でも約13秒で）止まり、次の入力ターンへ移ります。

### コマンドの組み立て方

- **行動を選ぶ**：移動（歩く・走る・追いかける・回避・乗り越える・飛び降りる）、攻撃（殴る・掴む・体当たり・フェイント・投げる）、守り・様子（ガード・受け流し・潜む・見回す・観察）、物（拾う・手放す・持ち物を使う・操作する・開ける・閉める・押す・引く・物音を立てる・体を払う）、スタンド（出す・先行させる・戻す）、待つ、そして自分の能力の各効果。ボタンにマウスを乗せると説明が出ます。
- **対象を選ぶ**：敵（名前のボタン）・味方・自分・方向（8方向の矢印／敵の方へ／敵から離れる／物陰へ）・地点や物（戦場をクリック）。扉・窓・自販機・落ちている物などは、クリックするとその物が対象になります。
- **経路**：「歩く」「走る」を選んで戦場を続けてクリックすると、通る地点を順に足していけます（「経路を確定」で終わり）。戦場に番号つきの印と線で表示されます。
- **条件（〜したら）**：手順ごとに「敵が◯m以内に見えたら」「殴りかかってきたら」「攻撃を受けたら」「敵が倒れたら」「HPが◯以下になったら」などを付けられます。何秒まで待つかも決められ、その間に満たされなければその手順は飛ばします。例：「待つ（条件：敵が5m以内）」→「回避」で、敵が来たら跳ぶ。
- **細かい指定**：待つ・ガード・潜むの秒数、エコー・ビーチの体数、セブンス・サンの反射回数など。
- **行動ゲージ**：手順ごとの見積もり時間と、1ターンの上限（最大5手順・約10秒）を表示します。足りない手順は理由つきで赤く表示され、実行されません。手順は◀で前に移す、✕で消すことができます。
- **セリフ**：右上の欄に書くと、実行の始めに喋ります（相手に聞こえれば、相手の作戦の材料になります）。
- 「文章で」を押すと、これまでの文章による指示（ゲーム内蔵の簡易解析）も使えます。「できること」の例文をクリックした時も文章入力になります。
- 何も組み立てずに決定すると「様子を見る」になります。実行中は Space で一時停止できます。再生速度も変えられます。
- 敵は見えている時だけ表示されます。物音は波紋で表示されます。

### 3D表示

戦闘画面の「表示」ボタンを押すたびに、2D → 3D → TPS（肩越しの視点）→ 2D と切り替わります（選んだ表示は次回も使われる）。

- **TPS**：自分の後ろ・少し右上から、向いている方向を見るカメラ。向きが変わるとカメラもゆっくり回り込みます。画面を横にドラッグするか Q / E キーで見回せます。操作はいつもどおり文章の指示です。

- 建物・壁・木箱・車などは、ゲームの中の位置と高さのまま箱で立てています。キャラクターとスタンドは今のキャラチップ（ドット絵）を、カメラの方を向く板に貼って立たせています。
- 「拡大表示／全体表示」で、自分を後ろ斜め上から追うカメラと、戦場全体を見下ろすカメラを切り替えます。画面を横にドラッグするか、Q / E キーでカメラを回せます。
- 自分が1階にいる時は2階の床と壁が、自分のいる建物の壁と、カメラと人物の間にある物は透けて見えます。
- クリックで座標や物の名前を入力欄に入れる機能は、3D表示でも使えます。
- 描画には Three.js 0.160（MIT ライセンス、`public/vendor/`）を使っています。ネットにつながっていなくても動きます。

### CPU観戦モード

- タイトル画面の「遊び方」で「CPU同士を観戦する」を選ぶと、自分のキャラも含めて全員を CPU が操作します（作戦は内蔵の思考。Gemini が使える時はセリフだけ Gemini）。
- 観戦中は全員の姿・行動計画・ログが見え、入力欄は出ません。再生速度は4倍まで上げられます。どの形式でも観戦できます（2チームの戦いはチームA・チームBの表示、バトルロワイヤルは生存人数とチームの色の体力バー）。

- **自動カメラ**：殴り合っている・殴られた・能力を構えている人物など、見どころのある人を自動で映します。「カメラ」ボタンで1人に固定もできます。
- **体力の綱引き**：画面の上に、両チームの残り体力の割合を出します。3D表示では頭の上に体力ゲージも出ます。

### バトルロワイヤル

全員が1人1チームで戦い、最後の1人になれば勝ちです。警察が来た時は、生き残っている人の中で与えたダメージが一番多い人の判定勝ち。CPU は自分以外の全員を敵として、近くの敵の出方を想定しながら先読みします（他の敵同士が削り合うのも自分の得として数えます）。

### 2対2

- 相手チームを全員倒せば勝ち。自分が倒れても味方が残っていれば、味方の視点で観戦して決着まで進みます。
- 味方とは連絡を取り合っている扱いで、味方の位置・様子は常に分かり、味方が見た敵の位置は「報告」として共有されます。
- 「鷺沼を殴る」「セブンス・サンを追いかける」のように敵の名前（姓・名・スタンド名）を書くとその敵を狙います。書かなければ見えている一番近い敵。「味方の所へ走る」で合流できます。
- 投げた物・跳弾は味方には当たりません（自分の跳弾は自分に当たります）。

### 行動の一覧（増やしたもの）

誰でも使える行動：

| 行動 | 内容 | 書き方の例 |
| --- | --- | --- |
| 掴み | ガード・受け流しを崩して1.2秒動けなくする。構えの間に殴られると潰される | 「敵がガードしたら掴みかかる」 |
| 受け流し | 0.8秒の構え。正面から殴ってきた相手に打ち返す | 「受け流しの構えで待つ」 |
| フェイント | 殴る構えだけ見せて、相手のガード・回避を空振りさせる | 「フェイントしてから殴る」 |
| 体当たり | 4m突進。当たれば突き飛ばして転倒、壁なら叩きつけ | 「敵に体当たりする」 |
| 潜む | 動かずに気配を消す。6mより遠くから見つからない | 「じっと身を潜める」 |
| 見回す | ぐるりと一周見回して、背後の敵にも気づく | 「周りを見回す」 |
| 物音を立てる | 小石を投げて離れた所で音を出し、注意を逸らす | 「右に小石を投げて物音を立てる」 |
| 乗り越える | 1.6m以下の木箱・車・塀などを越える | 「木箱Aを乗り越える」 |
| 道具を使う | 消火器で煙幕（視線を遮る）、傘で飛び道具を防ぐ | 「消火器で煙幕を張る」 |

近接は「殴り→掴みに勝つ／掴み→ガード・受け流しに勝つ／受け流し→殴りに勝つ」の読み合い。条件に「敵がガードしたら」「敵が転んだら」も使えます。

キャラ固有に増やした効果：

| キャラ | 効果 | 書き方の例 |
| --- | --- | --- |
| 十河 | 真上に打ち上げる（開けた所で触れた敵を10m打ち上げ、落ちて8ダメージ・転倒） | 「敵を真上に打ち上げて、落ちたら殴る」 |
| 錠二 | 外壁へ叩きつける（自分の密室の中で、8ダメージ＋激突6。開けた出口の炎へ投げ込めば火傷12） | 「敵を炎の壁に叩きつける」 |
| 七海 | 無音の結界（半径3mの音を10秒消す）／足音の行列（誰かが歩いているような足音を別方向へ） | 「自分の周りに無音の結界を張る」 |
| 鷺沼 | 玉を撒く（走って踏むと転倒）／牽制射撃（0.5秒ごとに4発） | 「足元に玉を撒いてから離れる」 |
| 御厨 | 車両を走らせて口を残す／食いしばって噛む（腕の口は盾）／口から喋る | 「車両を敵へ走らせて、敵の背中に口をつける」 |
| 蛇穴院 | 足場を崩す／得物を崩す／壁に穴を開ける／床を仕込む／元に戻す | 「「前世から知ってる気がする」と話しかけながら、敵の足元の床を粉にする」 |

七海の配置した個体のすぐそばで敵が音を立てると、その敵の正確な位置が七海と味方に伝わります。

### 窓と密室

- 窓は「枠の開閉」と「ガラスの割れ」を別々に持つ。枠が開いているか、ガラスが割れていれば通り抜けられる。
- ガラスが割れても枠は閉められ、ホテル・カリフォルニアの密室の判定は枠が閉まっているかで決まる（コンビニのはめ殺しのガラスは枠が開かないので、割れても閉まった扱い）。
- 「敵が入ってきたら扉を閉める」のような待ち伏せの条件が使える。錠二はスタンドを出していれば少し離れた扉も素早く閉められる。

### スタンドを出す・先行させる

- 「スタンドを出す」「スタンドを右へ先行させる」「スタンドで角の先を覗く」「スタンドを戻す」のように書けます。
- 先行させたスタンドは本体から射程（十河約2m・錠二約1.5m・鷺沼約1.2m・蛇穴院約5m）まで離れられ、壁もすり抜けます（壁越しに覗く・壁の向こうの扉を閉める）。スタンドの位置からも周りが見えるので、角の先や窓の外を覗けます。
- 出している間は近接攻撃でスタンドが敵へ飛び出すため、拳の届く距離が伸びます（本体から離れた所で当たった拳は威力7割）。鷺沼の弾はスタンドの位置から撃てます。
- 敵の飛び道具がスタンドに当たると受け止めますが、本体にも3割の反動が返ります。
- 出している間はスタンドエネルギーが回復せず、毎秒2ずつ減ります（尽きると戻ります）。七海のエコー・ビーチは群体なので使えません。

### ガン待ち対策（追加分）

- **安全地帯が徐々に狭まる。** 開始時に中心がランダムに決まり（画面に紫の円で表示）、25〜55秒・75〜105秒・120〜150秒の3段階で縮んで、最後は半径5mになる。円の外にいると毎秒2ダメージ（段階が進むごとに+1）。次に縮む先は点線で表示される。CPU は外に出そうになると内側へ戻る。

- 七海が自分で立てた音（物を叩いた音など）も轟音の材料になる（以前の「弱い音」扱いは廃止）。轟音は大きな音3つ以上で相手が転倒・難聴になる。
- 轟音を鳴らすと、個体が飛んできた方向から七海のおおよその居場所（±3m）が相手に伝わる。
- 同じ建物・同じ場所（半径5m）に40秒とどまると、住人・店員・通行人に気づかれて「誰かいるぞ！」と騒がれ、居場所が敵に知られる（10秒前に予告が出る）。

### 回復と、操作できる物

- 回復アイテム：缶ジュース（+12・1秒）・おにぎり（+15・1.5秒）・包帯（+18・2秒）・救急箱（+35・3秒）。拾って「使う」（使っている間に殴られると中断）。例：「救急箱を拾って手当てする」
- 自動販売機：缶ジュースを買える（1台3本）。水飲み場（公園）：水を飲んで10回復（25秒に1回）。
- 発電機（工事現場）：動かすと45秒間、半径12mの小さな音（足音・声など）がうなりでかき消される。
- ゴミ箱：陰に深く隠れる（1.5mより遠くから見つからない）。レジカウンター：防犯ブザーを鳴らす（遠くまで響く）。

### 時間制限（ガン待ち対策）

- 120秒でパトカーのサイレンが聞こえ始め、180秒で警察が到着して戦闘終了。その時点で「相手に与えたダメージ」が多い側の判定勝ち（同点は引き分け）。
- 先にダメージを取った側が有利になるので、負けている側は待っていても勝てない。CPU も判定で負けていれば攻めに転じる。
- 経過時間・警察到着までの残り・与ダメージは戦闘画面の下に表示されます。

### 音の表示

- 聞こえた音は波紋と「♪ 種類」の札で表示（姿の見えない所の音は「？」付きの推定位置）。音の種類ごとに色が違う。
- 見えている所で鳴った音は、届く範囲を点線の輪で一瞬示す（自分の出した音がどこまで届くか分かる）。
- 防犯アラームが鳴っている車には、鳴り終わるまで印が出る。

### 演出

- 打撃が当たると、威力に応じたヒットストップ（一瞬の停止）・画面揺れ・集中線・擬音（ドゴォ、バキィ、ドギュン…）・大きなダメージ表示が出ます。
- 大ダメージは画面がフラッシュし、再起不能の瞬間はスローモーションになります。構え中のキャラには「ゴゴゴ」が出ます。
- 至近距離の殴り合いの瞬間・大ダメージ・再起不能の時は、カメラが寄って（クローズアップ・上下の黒帯）スローモーションになります（戦闘画面の「寄り・スロー」ボタンで ON/OFF）。
- 効果音は `public/sound/` の音声（Kenney の CC0 素材と合成音。`public/sound/README.md` 参照）を、音の種類と距離に応じて鳴らします。住宅街では環境音も小さく流れます（「効果音」ボタンで ON/OFF）。
- エフェクト素材のスプライトシートを `public/fx/effects.png` に置くか、タイトル画面で選ぶと、その画像で描きます（`public/fx/README.md` 参照）。

### CPUの考え方

- **戦い方の型**：近接型（十河・錠二）は詰めて殴り続け、中距離型（蛇穴院）は約5m、遠距離型（七海・鷺沼・御厨）は10〜14mの間合いを保つ。逃げる時は、角や安全地帯の外に追い詰められない場所を選ぶ。
- **先読み**：毎ターン、いくつかの作戦の候補（いつもの作戦・別の乱数での作戦・距離を取る・詰める・各能力を狙う など）を盤面の写しの上で6秒先まで試し、与えるダメージ・受けるダメージ・間合い・安全地帯で比べて一番良いものを選ぶ。
- **相手の読み**：相手の出方は「いつもどおり」「一気に詰めてくる（遠距離型なら離れる）」「能力で攻めてくる」の3通りを想定して試し、平均と最悪の場合を半々で見て、読みが外れても大崩れしない案を選ぶ（1回の判断に最大1.5秒）。
- **性格と気分**：キャラクターごとに攻め気・用心深さ・博打好き・口数が違い（例：錠二は攻め気が強く、七海は用心深く無口、鷺沼は博打好き、蛇穴院はおしゃべり）、先読みの採点の重みが変わる。体力の差や被弾で気分（優勢・劣勢・追い詰められた・探索中）が変わり、追い詰められると攻め気の強い者は捨て身に、用心深い者は逃げに傾く。
- **セリフ**：敵を見つけた・一撃を入れた・強く殴られた・体力が少ない・押している／押されている・能力を使う、などの場面ごとに、キャラクターらしい一言を喋る。潜んでいる時や、御厨が食いしばっている時は黙る。
- **公平さ**：写しの中では、見えていない敵は「最後に見た場所」に置いて考える（本当の位置は使わない）。プレイヤーの入力内容も見ない。
- 考えるのはプレイヤーが入力している間で、候補を1つ試すごとに画面の描画に譲るので、画面は止まらない。

- **植え込み**：通れるが遅く、葉擦れの音がする。中にいると、2.5m以内に近づかれない限り見つからない（中から外は見える）。
- **車**：遮蔽物になる。殴る・物をぶつけるなどすると防犯アラームが鳴り、半径40mに聞こえる（陽動に使える）。
- **重い物**：商品棚・自販機・ドラム缶なども押したり弾いたりできる。
- 広いマップでは「拡大表示」（Z キー）で自分の周りを大きく映せる。
- マップを追加するには `public/js/engine/maps.js` に配置を書き、`MAPS` に登録する。

## 仕組み

```
自然文 ─▶ Gemini（またはローカル解析）─▶ 生の行動計画(JSON)
                                         │
                       compilePlan：行動・能力・対象・射程・予算を検証
                                         ▼
               ゲームエンジン：移動・命中・ダメージ・能力効果を確定
```

- Gemini は CPU のセリフの言い換えだけに使います。プレイヤーの行動はコマンド（または内蔵の簡易解析）で、CPU の作戦は内蔵の思考で決めます。存在しない能力や効果は検証で弾かれ、勝敗はエンジンの物理状態とルールで決まります。
- CPU の観測（`buildObservation`）には、CPU本人が見聞きした情報だけが入ります。見えていない敵の現在位置、未観察の能力、プレイヤーの指示文は含まれません。
- CPU の作戦は入力ターンの開始時点で立てるので、プレイヤーの入力内容は使われません。CPU のセリフは、内蔵の思考が「喋る」と決めた時だけ Gemini に言い換えさせ、3秒以内に返らなければ内蔵のセリフをそのまま使います。

### 武器（拾える物）

初期装備はありません。マップのあちこちに置かれた物（花瓶・瓶・包丁・フライパン・鉄パイプ・ブロック・レンチ・角材・傘・消火器・石・木の枝）を拾って使います。「花瓶を拾って投げる」「鉄パイプを拾って殴る」のように書きます。持てるのは1つで、持っている物で殴ると威力・間合いが変わり、投げると手放します。花瓶や瓶は当たると割れます。

### キャラクター画像

- **ブラウザから**：タイトル画面の各キャラクターの「本体の画像…」「スタンドの画像…」ボタンで画像を選ぶと、その場で表示されます（ブラウザに保存され、次回以降も表示。「消す」で削除）。
- **ファイルで**：`public/img/` に `<id>.png`（本体）と `<id>_stand.png`（スタンド）を置きます（jpg・webp も可）。詳しくは `public/img/README.md`。
- 表示される場所：キャラクター選択カード、戦闘画面の左右の情報欄（本体）、能力発動時のカットイン（スタンド画像。無ければ本体）。

## 高さと建物

- 1階分は3m。2階建ての家（左の家・佐藤家・鈴木家・高橋家）は階段で上り下りできる（約1秒）。
- 物体には高さがあり、視線と飛び道具は高さも含めて判定する。ブロック塀（1.8m）や車（1.5m）は地上の視線を遮るが、2階の窓からは越えて見下ろせる。床・天井は階をまたぐ視線を遮る。
- 扉は閉まっていると通れず見通せない（歩いてぶつかると自動で開ける）。扉と窓は開け閉めでき、開いた窓は通り抜けられる。コンビニのガラス窓は開かず、割るしかない。
- 2階の窓から飛び降りられる（窓が閉まっていれば突き破る）。
- 表示は斜め見下ろし。建物は屋根で覆われ、中に入ると屋根が外れて今いる階が見える。

## 能力の追加

1. `data.js` の `ABILITIES` に能力データ（効果・対象・射程・発動時間・クールダウン・コスト・弱点など）を追加

3. `data.js` の `CHARACTERS` で、キャラクターの `abilities` に追加
