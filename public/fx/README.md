# エフェクト素材

`effects.png`（webp / jpg も可）という名前で、エフェクトのスプライトシート1枚をここに置くと、戦闘の演出に使われます。タイトル画面の「素材の画像を選ぶ…」から選んでもかまいません（ブラウザの IndexedDB に保存されます）。

- 各コマの切り出し位置は `public/js/fx.js` の `ATLAS`（横幅1316pxのシートを基準にした座標）。画像の横幅が違っても、比率で合わせます。
- 背景が透過されておらず市松模様が描き込まれている画像でも、各コマの縁の色を背景とみなして自動で抜きます。
- 切り出し位置と背景の抜け具合は `fx.html`（タイトル画面の「切り出し位置を確認する」）で確認できます。
- 素材が無いコマは、これまでどおりプログラムで描いた演出になります。
