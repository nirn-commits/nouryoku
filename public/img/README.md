# キャラクター画像

画像の出し方は2通りあります。

1. **ブラウザから選ぶ（おすすめ）**：タイトル画面のキャラクターカードにある「本体の画像…」「スタンドの画像…」ボタンを押して画像を選びます。長辺640pxに縮小してブラウザ（localStorage）に保存されるので、次回以降も表示されます。別のブラウザや別の端末には引き継がれません。
2. **ファイルを置く**：このフォルダに次の名前で画像を置きます（拡張子は png / jpg / jpeg / webp）。ブラウザから選んだ画像があればそちらが優先されます。

| --- | --- |

| `sogo_stand.png` | パーペンディキュラー |
| `kito.png` | 鬼頭 錠二 |
| `kito_stand.png` | ホテル・カリフォルニア |
| `nanami.png` | 七海 灯 |
| `nanami_stand.png` | エコー・ビーチ |
| `saginuma.png` | 鷺沼 玲司 |
| `saginuma_stand.png` | セブンス・サン |

表示される場所：キャラクター選択カード／戦闘画面の情報欄（本体）／能力発動時のカットイン（スタンド。無ければ本体）。
