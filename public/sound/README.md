# 効果音・BGM

効果音（MP3 / OGG / WAV）と BGM を置く場所です。今はまだ読み込んでおらず、効果音はブラウザ内で合成した音を鳴らしています。素材がそろいしだい読み込み処理を追加します。

| ファイル名（予定） | 使う場面 |
| --- | --- |
| `se_hit_light` / `se_hit_heavy` | 打撃（軽い・重い） |
| `se_guard` | ガード |
| `se_flick` / `se_ricochet` | 玉を弾く・跳弾 |
| `se_glass` | ガラス・花瓶・瓶が割れる |
| `se_door` | 扉・窓の開閉 |
| `se_flame` | 密室の炎 |
| `se_roar` | 七海の轟音 |
| `se_launch` | 十河の弾き出し |
| `se_alarm` | 車の防犯アラーム |
| `se_land` | 着地・転倒 |
| `se_ko` | 再起不能 |
| `se_ability` | 能力発動 |
| `bgm_input` / `bgm_battle` | 入力ターン用・実行中用 |
